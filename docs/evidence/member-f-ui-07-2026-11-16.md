# TASK-UI-07 staff accessibility verification

Member F implemented and tested this slice on 16 November 2026. Member A review is pending. Base `dev` was `5de0582`. This work supports AT15 with frontend checks using synthetic API fixtures.

| Workflow | What the browser checks at 1366×768 and 1024×768 |
| --- | --- |
| Sign-in and role shell | Existing sign-in viewport checks, skip link as the first keyboard stop, and focus beyond the staff navigation |
| Reception scheduling | Labelled room and therapist selectors, focus on a reversed end time in the booking and availability forms, associated error text, and no page overflow |
| Therapist scheduling | Keyboard access from the delivery action to observations and completion |
| Dispensary | Visible focus on a labelled trace results table, horizontal scroll inside the table, and Sinhala and Tamil glyphs rendered by the bundled fonts |
| Billing | Keyboard entry into the draft dialog, focus within the modal, Escape and focus return |
| Report reader | Keyboard access to the labelled outstanding-invoices table and no page overflow |
| Staff administration | Skip link to account management, keyboard entry into the create dialog, Escape and focus return |
| Patients and clinical | Existing [Member B UI-07 checks](member-b-ui-07-2026-11-06.md) cover both layouts, patient registration with Unicode and patient/consultation validation focus |

The billing receipt regression also checks Escape from invoice detail, linked amount validation and preservation of the original receipt retry. The two new screenshot cases save `draft-dialog.png` and `traceability.png` in the corresponding local Playwright output directories for each viewport.

The browser assets are the Sinhala subset of [Noto Sans Sinhala](https://github.com/google/fonts/tree/main/ofl/notosanssinhala) (Google Fonts v36) and the Tamil subset of [Noto Sans Tamil](https://github.com/google/fonts/tree/main/ofl/notosanstamil) (v31), served locally under `frontend/public/fonts` with their SIL Open Font License texts. The fonts are requested only for their Unicode ranges.

On Windows, lint, the production build including TypeScript, 16 unit tests, and 37 Edge browser tests passed. Browser tests used synthetic data. Visual inspection of the captured tablet screenshots confirmed the dialog fit and the mixed-script name was readable inside the scrollable results. Module owner review and the wider AT15 acceptance remain open.
