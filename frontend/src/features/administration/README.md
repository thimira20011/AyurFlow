# Administration interface

`session.tsx` owns memory-only session state, startup/focus restoration, expiry handling and logout. `sign-in-form.tsx` uses the existing cookie API. `/workspace` shows role work areas; the shared layout guard is UI behavior, never a substitute for Go role/record checks. `apiMutation` obtains current CSRF and never automatically retries writes. `/administration` implements staff listing/creation, role selection and disabling through the protected AUTH-04 API. See [login setup](../../../../docs/api/auth-04-login.md), [the staff contract](../../../../docs/api/auth-04-staff.md) and [the administration guide](../../../../docs/guides/member-a-administration.md) for setup, verification and staff instructions. No public signup, remember-me policy or password recovery is introduced.
